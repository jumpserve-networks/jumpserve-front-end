# Bundled Geist fonts

These unmodified variable WOFF2 files come from Vercel's `geist` npm package,
version **1.7.2**:

- Source: https://www.npmjs.com/package/geist/v/1.7.2
- Original archive: https://registry.npmjs.org/geist/-/geist-1.7.2.tgz
- Archive SHA-256: `88cbfaca51646078f3172802643691bb8fe2df15ca4c455b1b101e49b7d469a6`
- `Geist-Variable.woff2`: `dist/fonts/geist-sans/Geist-Variable.woff2`
- `GeistMono-Variable.woff2`: `dist/fonts/geist-mono/GeistMono-Variable.woff2`

Both fonts are distributed under the SIL Open Font License 1.1; the original
copyright notice and license are preserved in `LICENSE.txt`.

The root layout uses `next/font/local` with the existing CSS variables and
weights 100–900. The fonts are served by Next.js as local static assets, so
development and production builds do not need to contact Google Fonts.
